YouTube Thumbnail Maker (1280×720)

Build thumbnails at YouTube’s recommended 16:9 · 1280×720 size. Add text and backgrounds in a few clicks, then download a PNG—no account required.

Create for free

Thumbnail checklist

  • Recommended size: 1280×720 pixels (16:9)
  • Keep key text and faces near the center
  • Use high contrast and bold type for readability
  • Export PNG and upload it in YouTube Studio

How to make one

  1. Open the editor and choose the YouTube thumbnail preset.
  2. Add copy, styles, and fonts in the Text tab.
  3. Set a background color or photo.
  4. Save image to download a PNG.
