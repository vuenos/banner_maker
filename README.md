# Free Youtube Thumbnail and Banner Maker

## You can create Youtube and Tiktok Thumbnail for free
(유튜브 썸네일, 배너 무료 제작)

https://banner-maker-vuenos-projects.vercel.app

### 개선 내용

- 화면 배율과 저장 크기를 나눴습니다. 맞추기, 50%, 100%는 보이는 크기만 바꾸고, 다운로드되는 PNG는 가로·세로 픽셀 그대로입니다.
- 용도별 크기를 바로 고릅니다. 가로 영상 1920×1080, 세로 영상 1080×1920, 썸네일 1280×720, 채널 배너 2560×1440.
- 채널 배너에는 모든 기기에서 보이는 안전 영역(1546×423)을 점선으로 보여 줍니다. 점선은 파일에 들어가지 않습니다.
- 글자, 색, 배경 사진을 한 상태에서 다룹니다. 줄바꿈이 유지되고, 사진은 버튼으로 지울 수 있습니다. 크기는 64–4096px로 제한됩니다.
- 글자 정렬, 그림자, 외곽선, 드래그 이동, 실행 취소와 다시 실행을 지원합니다. 작업 중인 내용은 브라우저에 남습니다.
- 색 선택 창은 바깥을 누르면 닫힙니다.
- 조작부를 한 줄로 모아 좁은 화면에서도 보이게 하고, 묶음 안의 간격과 묶음 사이 간격을 맞췄습니다.
- 선택한 글꼴만 불러오고, 아이콘과 매니페스트는 `public`에서 제공합니다.
