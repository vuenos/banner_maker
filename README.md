# Free Youtube Thumbnail and Banner Maker

## You can create Youtube and Tiktok Thumbnail for free
(유튜브 썸네일, 배너 무료 제작)

https://www.thumbnail.co.kr/

### 개선 내용

- 화면 배율과 저장 크기를 나눴습니다. 맞추기, 50%, 100%는 보이는 크기만 바꾸고, 다운로드되는 PNG는 가로·세로 픽셀 그대로입니다.
- 용도별 크기를 바로 고릅니다. 유튜브 영상 1920×1080, 숏폼 영상 1080×1920, 유튜브 썸네일 1280×720, 유튜브 채널 배너 2560×1440.
- 채널 배너에는 모든 기기에서 보이는 안전 영역(1546×423)을 점선으로 보여 줍니다. 점선은 파일에 들어가지 않습니다.
- 글자를 여러 레이어로 추가·선택·삭제할 수 있습니다. 줄바꿈이 유지되고, 색·배경 사진·크기는 한 상태에서 다룹니다. 크기는 64–4096px로 제한됩니다.
- 글자 스타일 프리셋을 고를 수 있습니다. 기본, 예능 타이틀, 스펙트럼(청록→분홍 그라데이션·흰 외곽선), 블러시(흰→분홍 그라데이션·검정 외곽선).
- 글자 정렬, 그림자, 외곽선, 드래그 이동, 실행 취소와 다시 실행을 지원합니다. 선택한 글자 왼쪽 위에 이동 손잡이가 붙습니다.
- 상단 **초기화**로 크기·글자·배경·히스토리를 처음 상태로 되돌립니다. 작업 중인 내용은 브라우저에 남습니다.
- 색 선택 창은 바깥을 누르면 닫힙니다.
- 선택한 글꼴만 불러오고, 아이콘과 매니페스트는 `public`에서 제공합니다.

### UI

- Studio Dark 레이아웃입니다. 상단 바, 왼쪽 조작 패널, 넓은 미리보기 스테이지로 나뉩니다.
- 프리셋은 비율 미리보기가 있는 2×2 비주얼 카드입니다. 마우스를 올리면 용도 설명이 나옵니다.
- 스타일은 스와치 카드로 고르고, 글자 레이어 칩으로 여러 문구를 전환합니다.
- 이미지 저장은 상단 코랄 CTA에 두고, 배너 영역이 화면 대부분을 차지하도록 맞췄습니다.
- 좁은 화면에서는 조작 패널이 위로, 미리보기가 아래로 쌓입니다.
